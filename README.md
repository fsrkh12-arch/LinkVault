# LinkVault

[Open the full app](https://linkvault-8u34.onrender.com/) · [Open the browser demo](https://fsrkh12-arch.github.io/LinkVault/)

I created LinkVault on my own as a personal tool to keep my bookmarks private and easy to access in one place. It also helped me learn how authentication, databases, and web applications work together.

In the full app, users can save links, add tags, search, mark favorites, and manage their own collection. The free hosted app may take a moment to wake up, and its database is not permanent. The separate browser demo stores links only in the current browser.

**Technologies:** Python, Flask, SQLite, HTML, and CSS.
